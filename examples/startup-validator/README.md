# Egghead Startup Validator

A demo that validates a startup idea using the Vegapunk satellites.

- Edison proposes angles and strategy, Pythagoras researches the market, Lilith attacks the weak points, Shaka checks coherence and gives final approval, Atlas and York produce and tidy the deliverable.
- Research uses free web search via DuckDuckGo; no extra API keys are required.
- **Status:** 🚧 Planned — description only; no code yet.
- **Filled in:** Phase 3 — LangGraph flavor + Startup Validator demo.
- It consumes the framework; the framework does not depend on it.
